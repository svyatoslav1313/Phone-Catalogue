# Phone Catalogue — Online Store

This project is a modern, fully functional product catalog for smartphones and accessories. Built with a focus on component-based architecture, it features a fully responsive interface, advanced filtering, and a dedicated shopping experience across all devices.

## Live Preview

Experience the store here: [Phone Catalogue Demo](https://svyatoslav1313.github.io/Phone-Catalogue/)

## About the Project

The goal of this application is to provide users with a seamless shopping experience on any device, from mobile phones to wide-screen desktops. The project implements robust state management for the shopping cart and favorites list, ensuring a consistent and interactive user journey.

## Technologies Used 💻

### Core

- **React** — Component-based UI development with Hooks.
- **TypeScript** — Static typing for robust and error-free code development.
- **SCSS Modules** — Scoped and modular styling to prevent class name collisions and improve maintainability.
- **React Router** — Client-side routing for seamless page transitions.

### Methodology & Tools

- **Component-Driven Development** — Reusable UI components for a consistent design system.
- **Lucide-react** — A clean and consistent icon library for enhanced UI/UX.
- **Git/GitHub** — Version control and hosting.

## Features

- **Advanced Filtering & Sorting:** Quickly find devices by category or sort them by Newest, Alphabetical, or Price (cheapest first).
- **Favorites & Shopping Cart:** Effortlessly manage your selections with real-time updates powered by React Context.
- **Fully Responsive Design:** A mobile-first approach that scales beautifully to tablets and large desktop monitors.
- **Product Details:** Comprehensive technical specifications and interactive image galleries for every device.

## Setup Instructions

Follow these steps to set up the project locally:

1. **Clone the repository:**

```bash
git clone https://github.com/svyatoslav1313/Phone-Catalogue.git
cd Phone-Catalogue
```

2. **Install dependencies:**

```bash
npm install
```

3. **Run the project locally**

```bash
npm start
```
